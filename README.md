# Anitta George & Amal — Classic Christian Wedding Invitation

A responsive React + Vite wedding invitation starter. Date, time, church/venue and address are placeholders because those details have not been supplied.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install` then `npm run dev`.
4. Open the local URL shown by Vite.

## Customize
- Edit the `[Add ...]` placeholders in `src/main.jsx` with the confirmed wedding details.
- Replace the photo placeholder area and gallery tiles with your photos when available.

## Deploy to Vercel
1. Push this project folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Vite**; Build command: `npm run build`; Output directory: `dist`.
4. Click **Deploy**.
